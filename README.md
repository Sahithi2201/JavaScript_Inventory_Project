# JavaScript Assignments and Capstone Project

## Project Overview

This repository contains six JavaScript assignments and a capstone mini project completed as part of the JavaScript curriculum.

## Assignments

### Assignment 1: Variables, Data Types, and Console Operations

* Declares variables using `var`, `let`, and `const`.
* Demonstrates data types using `typeof`.
* Displays values in the console.

### Assignment 2: Operators, Expressions, and Input Handling

* Collects bill amount and tip percentage using `prompt()`.
* Converts input values using `Number()`.
* Calculates the tip and total amount.

### Assignment 3: Conditional Logic Implementation

* Uses `if...else` statements, a `switch` statement, and a ternary operator.
* Evaluates a test score, assigns a grade, and displays pass/fail status.

### Assignment 4: Loop Control Structures

* Demonstrates `for`, `while`, and `do...while` loops.
* Uses `break` and `continue`.
* Prints a multiplication table and searches for a number that meets a condition.

### Assignment 5: Function Architecture and Scope

* Demonstrates regular functions and arrow functions.
* Uses function parameters and default values.
* Explores function and block scope.

### Assignment 6: Arrays, Objects, and Core Methods

* Works with an array of product objects.
* Uses `forEach()`, `filter()`, and `map()`.

## Capstone Mini Project: Interactive Product Inventory & Analytics Dashboard

The capstone combines JavaScript concepts in a console-based product inventory application.

Features include:

* Adding a product using user input.
* Validating product names and prices.
* Assigning product categories based on price.
* Searching inventory using loops and conditional statements.
* Calculating inventory value, tax, and discounts.
* Filtering affordable products.
* Generating a formatted inventory report.

## Project Files

* `assignment1.js` to `assignment6.js` — JavaScript assignment scripts.
* `assignment1.html` to `assignment6.html` — HTML pages for running the assignments.
* `capstone.js` — Capstone application logic.
* `capstone.html` — HTML page for running the capstone.

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the relevant HTML file in a browser.
4. Open the browser Developer Tools and select the Console tab to view the output.
5. Follow any prompts displayed by the application.
